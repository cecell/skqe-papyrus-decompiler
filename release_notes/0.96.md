Help that fits on a screen: pex help lists every op with one sentence, and each op has its own help with examples, also as JSON.

## Changed

- **pex help:** lists the ops, each with its main usage and one sentence, under "Use pex.exe <op> for detailed info." pex help --all still prints everything.
- **Help for one op:** pex <op> --help prints only that op's help, starting with its sentence and ending with examples. An op that needs an input prints it when given none.
- **JSON help:** --json prints any help as one line of JSON, with each op's summary, examples, usage and descriptions.
- **Archives:** script names with characters outside plain English are found the way the game finds them.

## Upgrading

Replace pex.exe with the new one.
