pex compile no longer writes the source file's path into the compiled script, and --user / --computer let you set the header's user and computer fields.

## Changed

- **Header source field:** a compiled script's header names its source file. Bethesda's compiler writes the path it was given there, which can include your Windows account name; pex compile now writes the file name alone.
- **--user and --computer:** new options of pex compile for the header's user and computer fields, which Bethesda's compiler fills with the Windows account and machine name. The defaults stay "skqe" and "papyrus".
- **--help:** every command accepts --help and prints the full help.

## Upgrading

Replace pex.exe with the new one.
