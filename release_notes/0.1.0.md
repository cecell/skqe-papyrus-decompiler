First release: a decompiler, compiler, assembler, auditor and FormID patcher for Skyrim's compiled Papyrus scripts, in one exe.

## What it does

- **pex decompile:** turns a compiled script (.pex) back into Papyrus source. Of the 14,026 vanilla scripts, 14,024 compile back to the identical script with Bethesda's own compiler.
- **pex compile:** a Papyrus compiler that needs no Creation Kit. On every vanilla source Bethesda's compiler can build, it produces the same script, and does all of them in about 3 seconds.
- **pex asm and pex assemble:** Papyrus assembly out and back in, in the syntax Bethesda's assembler reads.
- **pex audit:** 17 checks for scripts that can hang, pile up threads or call functions on None, with the function and source line of each finding.
- **pex diff:** what changed between two versions of a script, in plain English.
- **pex refs and pex patch:** lists every FormID a script passes to GetFormFromFile, and renumbers them in the compiled file, loose or inside a BSA, with an undo journal. Made for ESL conversion.
- **pex closure and pex deps:** whether every script a script needs is installed, and which script extender it needs.
- **pex winners:** which copy of each script the game loads.

## Good to know

- Works on Skyrim LE and SE scripts. Fallout 4 and Starfield scripts are refused.
- Reads scripts inside BSA archives directly; nothing needs extracting first.
- pex patch won't write while the game is running.
- The docs folder explains every command, check and number. Start with README.md.

## Upgrading

Nothing to upgrade from. Unzip anywhere and run pex.exe from a command prompt: pex help lists the commands.
