Open a .pex with pex.exe to decompile it in place, a new pex recompile command to change who a script says built it, and shorter hex FormIDs for pex patch.

## New

- **Open with:** running pex.exe with just a .pex file (right-click, Open with, or drag the file onto the exe) decompiles it to <name>.psc in the same folder. It asks before overwriting a source that already exists, and the window waits for Enter so the result stays visible.
- **pex recompile:** rewrites the header fields that say who built a script and from where (--user, --computer, --source-filename) in every script of a file, folder or archive, and changes nothing else. Loose files in place, archive members to --out, with --dry-run.
- **Icon:** pex.exe carries the xQE icon and a version block, so Explorer shows them on the exe and on .pex files associated with it.

## Changed

- **pex patch:** a hex FormID can be 0x plus 1 to 8 digits; 0x801 and 0x000801 mean the same thing.

## Upgrading

Replace pex.exe with the new one.
