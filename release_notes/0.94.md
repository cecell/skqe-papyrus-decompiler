pex audit gains six checks: impossible and always-true conditions, unreachable code, unused properties, states nothing enters, and properties no plugin fills.

## New checks in pex audit

- **condition-impossible:** an If, ElseIf or While whose test can never pass, such as x == 1 && x == 2, or an ElseIf an earlier test already covers.
- **condition-always-true:** a test that always passes, such as x != 1 || x != 2.
- **code-unreachable:** code after a Return, or an Else that no value can reach.
- **property-unused:** a property no script reads or writes.
- **state-unreachable:** a state nothing ever enters.
- **property-unfilled (with --fills):** a property the script reads that no plugin attaching the script fills, so it is None. --fills reads the script data of every active plugin.

## Good to know

- Checked on Bethesda's own scripts: every condition and dead-code finding there is a real mistake in the original source.
- The whole modded Data folder, with 2,424 plugins, audits in under 10 seconds with --fills.
- patterns.json now ships next to pex.exe; --fills needs it there.

## Upgrading

Replace pex.exe and add patterns.json next to it.
