pex.exe now carries the plugin catalog inside it: pex audit --fills needs no patterns.json beside the exe.

## Changed

- **One file:** the catalog pex audit --fills reads plugins with is built into pex.exe. The zip no longer contains patterns.json.
- **Newer catalog:** pex now uses the current Skyrim Query Engine library and its catalog. Audit results are the same as 0.94.

## Upgrading

Replace pex.exe with the new one. A patterns.json left next to it from 0.94 can be deleted; while it is there, pex uses it instead of the built-in copy.
