The decompiler's built-in list of event names now comes from the game's own scripts and SKSE only.

## Changed

- **Event names:** the list no longer includes event names taken from third-party mods. A function that a mod declared as an event under a name that doesn't start with "On" is now written as a Function. It compiles to the same script.
- **Zip contents:** the docs folder is no longer included. README.md and pex help describe every command.

## Upgrading

Replace pex.exe with the new one.
